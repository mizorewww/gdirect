# GDirect macOS GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete native macOS GUI and a one-command `.app` builder without coupling it to gdirect's Rust internals.

**Architecture:** An independent Swift Package owns all UI and process orchestration. A single CLI adapter invokes a pinned, bundled gdirect executable; `ls --json` is the only structured payload and all other commands use exit status.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Foundation Process, XCTest, Bash; no external Swift packages.

**Spec:** `docs/superpowers/specs/2026-10-25-macos-gui-design.md`

## Global Constraints

- All product files live under `macos/`; do not modify `src/`, root Cargo files, or existing release scripts.
- macOS 15+, host arm64 or x86_64, no third-party GUI dependencies.
- Default build uses pinned official CLI archives with pinned SHA256; local CLI requires explicit `--cli`.
- GUI never reads/writes gdirect SQLite and never persists credentials or transient CLI logs.
- No precise transfer percentage/ETA parsed from human output.
- Do not git-commit unless the user separately requests it.

## Review Focus

- Filenames containing spaces, tabs, newlines, or option-like prefixes must remain single arguments and produce safe unique output paths; cover in Tasks 1 and 3.
- A cancelled process that ignores SIGTERM must be reaped and its task must not later complete as successful; cover in Task 2.
- A failed/empty/truncated JSON listing must not erase the last usable folder view; cover in Task 3.
- OAuth stderr and arbitrary CLI errors must stay memory-only, length-capped, and redact URL query strings; cover in Task 2.
- Finder's minimal PATH and a missing/old rclone must produce a visible dependency error rather than a silent failure; cover in Tasks 2 and 4.
